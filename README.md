## Projects & Contributions

Some of the projects I'm most proud of working on include the following:
- **CensorCAT**: A simple, dynamic text censoring engine for Firefox that lets you curate what you want to see on the web (and how you want to see it). This was my senior project in college, and its one that I designed and built from the ground-up for my own use. I'm not the biggest fan of seeing inappropriate content on the web, and so having a tool like this (that is free to use entirely) is important to me. While it's not perfect, I learned a lot making it and am pretty proud of how it turned out!
- **Fuse Automobiles**: A final project site for a web backend course in college, this website is one I'm also quite proud of. Deployed on Render, it attempted to recreate all the core functions of a real car dealership website, including browsing and filtering car listings, editing cars, account systems and the protections that come with handling user data, interfacing with a PostgreSQL database, and employee/admin functions. It was a ton of work, but it turned out pretty good! While some database functions may be broken now due to not having a host (it was originally hosted through my college's own database service), you can check out the source code here: (Link coming soon!)
- **Ash**: An open-source declarative Elixir framework. During my final semester of college, I contributed to the framework's PostgreSQL integration by adding new features to the program's database migration generator, as well as improved documentation for other branches of the project.
- **TheWebSite**: My personal creative portfolio website, built to showcase my creative projects and passions outside of programming (such as music, graphic design, videos, etc.). It acts as a sort of separate zone away from the rest of the internet, and allows me to put my experience with web design and development tools to good use. While the soruce code for this project is private, you can see the final rendered version here on Neocities: (Link coming soon!)
- **Woolwav**: A custom Discord bot for streaming audio, with queuing and file browser functionality. While not a crazy project, it's one that I have a lot of fun working on and still update to this date with new features and fixes. Other Discord users can use the source code to launch and run their own audio bot (permitting compliance with the provided license files).
